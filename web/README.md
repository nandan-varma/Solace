# Solace — Marketing Site

Landing page and App Store support pages for [Solace](https://github.com/nandan-varma/Solace), an AI-native food scanner & diary tracker for iOS. Built with [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com), deployed to [solace.nandan.fyi](https://solace.nandan.fyi) via Vercel.

## Commands

| Command           | Action                                      |
| :----------------- | :------------------------------------------ |
| `npm install`       | Install dependencies                        |
| `npm run dev`       | Start local dev server at `localhost:4321`  |
| `npm run build`     | Build production site to `./dist/`          |
| `npm run preview`   | Preview the production build locally        |
